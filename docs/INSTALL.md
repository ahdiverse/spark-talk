# Installation

## Homebrew (Primary)

Official distribution model is Homebrew-first.

```bash
brew tap ahdiverse/spark-talk
brew install spark-talk
spark talk --help
```

## npm (Secondary)

```bash
npm install -g spark-talk
spark talk --help
```

## Local Development

From this repository:

```bash
npm install
npm run build
npm link
spark talk --help
```
